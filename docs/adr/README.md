# Architecture Decision Records

Each ADR records one decision: the context, what was decided, and what follows from it. ADRs are short and are not rewritten after they are accepted. A later decision that changes one gets its own ADR, and the old one's status becomes "Superseded by ADR-NNNN".

To add one, copy [`template.md`](template.md) to `NNNN-short-title.md` with the next number, and add it to the list below.

| ADR | Title | Status |
|---|---|---|
| [0001](0001-record-architecture-decisions.md) | Record architecture decisions | Accepted |
| [0002](0002-reset-and-refresh-time-format.md) | Reset and refresh times read as wall-clock times and countdowns | Accepted |
| [0003](0003-panel-moves-only-by-its-handle.md) | The floating panel moves only by its handle | Accepted |
| [0004](0004-provider-security-baseline.md) | Every provider meets the same security baseline | Accepted |
