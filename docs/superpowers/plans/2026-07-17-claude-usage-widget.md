# Claude Usage Widget Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship a macOS 14+ app that displays Claude subscription **plan-quota** usage (the 5-hour rolling window plus weekly limits) in a menu bar app and a WidgetKit widget, firing native notifications at configurable thresholds. The data model is provider-abstracted so xAI/OpenAI can be added later without refactoring; Claude is the only provider in v1.

**Architecture:** A local Swift package `UsageCore` holds **all** business logic and unit tests (`swift test`). Two Xcode targets defined via XcodeGen — a SwiftUI `MenuBarExtra` app `AgentUsageApp` and a WidgetKit extension `AgentUsageWidget` — both depend on `UsageCore` and share the latest `UsageSnapshot` through an App Group container. The app is the live view (60s refresh loop, notifications, writes the shared snapshot); the widget is a read-only consumer (OS-capped ~15 min timeline). Token access is **read-only** from the login Keychain item Claude Code writes.

**Tech Stack:** Swift 5.9+ (Swift 6 language mode OFF), SwiftUI, WidgetKit, UserNotifications, Security.framework, ServiceManagement, XcodeGen. XCTest for all unit tests. No third-party dependencies.

## Global Constraints

- **Deployment floor:** macOS 14.0. Package `platforms: [.macOS(.v14)]`; both targets `MACOSX_DEPLOYMENT_TARGET = 14.0`.
- **Language:** Swift 5.9+, Swift 6 strict-concurrency language mode OFF (use `@unchecked Sendable` only in test stubs where noted).
- **Read-only token:** never write, refresh, or rotate the Keychain token. Refresh endpoint is documented in the spec for a later enhancement — **do not build it**. Expired token or HTTP 401 → surface `.stale` / `.needsSignIn`, never refresh.
- **Exact strings (never change):** app bundle ID `com.gilad.agentusage`; widget bundle ID `com.gilad.agentusage.widget`; App Group `group.com.gilad.agentusage`; Keychain service `Claude Code-credentials`, account = current macOS user (`NSUserName()`).
- **Endpoint:** `GET https://api.anthropic.com/api/oauth/usage`, base overridable via `ANTHROPIC_BASE_URL`. Headers `Authorization: Bearer <accessToken>`, `anthropic-beta: oauth-2025-04-20`, `Content-Type: application/json`.
- **Non-sandboxed**, hardened runtime. Signing deferred: `CODE_SIGN_STYLE = Automatic`, `CODE_SIGN_IDENTITY = "-"` ("Sign to Run Locally"). Not for App Store.
- **Project generation:** `AgentUsage.xcodeproj` is generated by XcodeGen and git-ignored; `project.yml` is committed.
- **Thresholds:** notification defaults 80% (warning) / 95% (critical), configurable.
- **Commits:** Conventional Commits (`feat:` / `test:` / `chore:`), no ticket refs (personal project). Run all git commands from repo root `/Users/user/dev/personal/tokens`.
- **DTO caveat:** the exact `/usage` JSON shape is not 100% verified. Task 2 captures a real response to a fixture; the DTO/CodingKeys shown in later tasks are the *expected* shape and **must be reconciled** with the captured fixture before proceeding.

   ```swift
   import Foundation

   enum ClaudeUsageMapper {
       static func map(_ entries: [ClaudeUsageEntry],
                       warning: Double, critical: Double) -> [UsageLimit] {
           entries.compactMap { entry -> UsageLimit? in
               // v1: overage entries are not surfaced as limits.
               if entry.kind.contains("overage") { return nil }

               let label: String
               let id: String
               switch entry.kind {
               case "five_hour":
                   label = "Session (5h)"
                   id = "five_hour"
               case "seven_day":
                   label = "Weekly"
                   id = "seven_day"
               case "seven_day_opus", "seven_day_sonnet", "weekly_scoped":
                   if let name = entry.scope?.model?.displayName {
                       label = "Weekly (\(name))"
                       id = "\(entry.kind)#\(name)"
                   } else {
                       label = "Weekly (scoped)"
                       id = entry.kind
                   }
               default:
                   label = entry.kind.replacingOccurrences(of: "_", with: " ").capitalized
                   id = entry.kind
               }

               let resets = entry.resetsAt.map { Date(timeIntervalSince1970: $0) }
               let severity = Severity.from(percent: entry.percent,
                                            warning: warning, critical: critical)
               return UsageLimit(id: id, label: label, percentUsed: entry.percent,
                                 resetsAt: resets, severity: severity)
           }
       }
   }
   ```

   ```swift
   import Security

   public struct KeychainTokenReader: TokenReader {
       private let service: String
       private let account: String

       public init(service: String = "Claude Code-credentials",
                   account: String = NSUserName()) {
           self.service = service
           self.account = account
       }

       public func readClaudeToken() throws -> ClaudeToken {
           let query: [String: Any] = [
               kSecClass as String: kSecClassGenericPassword,
               kSecAttrService as String: service,
               kSecAttrAccount as String: account,
               kSecReturnData as String: true,
               kSecMatchLimit as String: kSecMatchLimitOne
           ]
           var item: CFTypeRef?
           let status = SecItemCopyMatching(query as CFDictionary, &item)
           switch status {
           case errSecSuccess:
               guard let data = item as? Data else { throw TokenReaderError.malformed }
               return try ClaudeCredentials.parse(data)
           case errSecItemNotFound:
               throw TokenReaderError.notFound
           case errSecAuthFailed, errSecInteractionNotAllowed, errSecUserCanceled:
               throw TokenReaderError.accessDenied
           default:
               throw TokenReaderError.accessDenied
           }
       }
   }
   ```

   ```swift
   import Foundation

   public struct NotificationState: Codable, Equatable, Sendable {
       /// key: "<limitID>#<threshold>" -> resetsAt (epoch seconds, 0 if none) it last fired for.
       public var fired: [String: Double]

       public init(fired: [String: Double] = [:]) {
           self.fired = fired
       }
   }

   public struct ThresholdCrossing: Equatable, Sendable {
       public let limit: UsageLimit
       public let threshold: Double

       public init(limit: UsageLimit, threshold: Double) {
           self.limit = limit
           self.threshold = threshold
       }
   }

   public enum ThresholdEvaluator {
       public static func evaluate(_ snapshot: UsageSnapshot,
                                   state: inout NotificationState,
                                   thresholds: [Double]) -> [ThresholdCrossing] {
           var crossings: [ThresholdCrossing] = []
           for limit in snapshot.limits {
               let window = limit.resetsAt?.timeIntervalSince1970 ?? 0
               for threshold in thresholds {
                   let key = "\(limit.id)#\(threshold)"
                   if limit.percentUsed >= threshold {
                       if state.fired[key] != window {
                           crossings.append(ThresholdCrossing(limit: limit, threshold: threshold))
                           state.fired[key] = window
                       }
                   } else {
                       // dropped below threshold — clear so it can re-fire on the next climb.
                       state.fired[key] = nil
                   }
               }
           }
           return crossings
       }
   }
   ```

   ```swift
   import Foundation
   import UserNotifications
   import UsageCore

   final class NotificationManager {
       private let center = UNUserNotificationCenter.current()
       private let defaults = UserDefaults.standard
       private let stateKey = "notificationState"

       func requestAuthorization() {
           center.requestAuthorization(options: [.alert, .sound]) { _, _ in }
       }

       func process(_ snapshot: UsageSnapshot) {
           guard snapshot.status == .ok else { return }
           let thresholds = [
               defaults.object(forKey: "warningThreshold") as? Double ?? 80,
               defaults.object(forKey: "criticalThreshold") as? Double ?? 95
           ]
           var state = loadState()
           let crossings = ThresholdEvaluator.evaluate(snapshot, state: &state, thresholds: thresholds)
           saveState(state)
           for crossing in crossings {
               post(crossing)
           }
       }

       private func post(_ crossing: ThresholdCrossing) {
           let content = UNMutableNotificationContent()
           content.title = "\(crossing.limit.label) at \(Int(crossing.limit.percentUsed.rounded()))%"
           content.body = "You've crossed the \(Int(crossing.threshold))% threshold for this limit."
           content.sound = .default
           let request = UNNotificationRequest(identifier: UUID().uuidString,
                                                content: content, trigger: nil)
           center.add(request)
       }

       private func loadState() -> NotificationState {
           guard let data = defaults.data(forKey: stateKey),
                 let state = try? JSONDecoder().decode(NotificationState.self, from: data) else {
               return NotificationState()
           }
           return state
       }

       private func saveState(_ state: NotificationState) {
           if let data = try? JSONEncoder().encode(state) {
               defaults.set(data, forKey: stateKey)
           }
       }
   }
   ```
