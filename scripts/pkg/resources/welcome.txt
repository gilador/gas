Tokens shows your Claude and OpenAI subscription usage in the menu bar.

This installer places Tokens in your Applications folder and starts it.

Two one-time prompts may follow:
  • macOS Keychain: Tokens reads the sign-in that Claude Code stores. Click "Always Allow".
  • If macOS says the app is from an unidentified developer, right-click Tokens and choose Open.

Tokens needs Claude Code signed in for the Claude numbers, and Codex CLI signed in for the OpenAI numbers.
