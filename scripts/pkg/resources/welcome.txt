Not a production build. You will be asked to approve for reinstall purposes: click "Allow".

gas shows your Claude and OpenAI subscription usage in the menu bar.

This installer places gas in your Applications folder and starts it.
If gas is already running, it quits it first and starts the new version when done.

Two one-time prompts may follow:
  • macOS Keychain: gas reads the sign-in that Claude Code stores. Click "Always Allow".
  • If macOS blocks gas, open System Settings → Privacy & Security and click Open Anyway.

gas needs Claude Code signed in for the Claude numbers, and Codex CLI signed in for the OpenAI numbers.
